# Contributing

Thanks for helping improve Lyricsfile. Bug reports, ideas, examples, and
documentation fixes are all welcome.

## How To Contribute

- For a small fix, open a pull request.
- For a format change or new field, start a GitHub Discussion or issue first.
- Add a short example when it helps explain your idea.

Please keep discussions friendly and focused. It is fine if an idea is not
fully worked out yet.

## Adding Examples

Example files belong in `examples/` and use the `.lyricsfile.yaml` extension.
Use original, fictional, or freely licensed lyrics. Please do not submit
copyrighted song lyrics without permission.
